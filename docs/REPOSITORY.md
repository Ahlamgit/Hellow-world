## Rename history

This repository was previously named **`Hellow-world`**. It was renamed to **Khadamati** to match the product name. GitHub redirects old URLs to the new repository name.

If your local clone still has the old remote:

```powershell
cd C:\Users\Ahlam\Documents\Khadamati
git remote set-url origin https://github.com/Ahlamgit/Khadamati.git
git remote -v
```

## Cloud agents (Cursor)

Cursor Cloud environments should be configured to clone **`Ahlamgit/Khadamati`**, not the former `Hellow-world` name. After renaming on GitHub, update the environment repository in the [Cursor Cloud dashboard](https://cursor.com/dashboard/cloud-agents).
