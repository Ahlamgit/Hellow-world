# ADR-007: Admin-Managed Promotions (No Ads Marketplace)

## Status
Accepted — 2026-07-24 (Master Prompt v1.0)

## Decision
V1 supports **admin-managed** advertisement packages, featured listings, promotion slots, and provider visibility.

Do **not** build a complex self-service advertising marketplace unless separately approved.

Store Dashboard may display promotion status / request visibility, but commercial ad inventory is admin-operated.

## Consequences
Answers Q-ADS-001..003 toward admin-managed model. Reduces Store Dashboard scope.
